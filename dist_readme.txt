========================================
  Soft Clipper — How to run
========================================

1. Unzip this whole folder anywhere (e.g. Desktop).

2. Double-click:  "Soft Clipper.exe"
   (Windows may show "Windows protected your PC" the first time.
    Click "More info" -> "Run anyway". This is normal for apps
    that are not code-signed.)

3. A black window opens and your browser launches automatically at
   http://127.0.0.1:8501
   Keep the black window open while you use the app. To quit, just
   close that window.

4. First time only: click the API Key button and paste your own free
   Google Gemini API key.
   Get one here:  https://aistudio.google.com/app/apikey

Your downloads and finished clips are saved next to the .exe in the
"downloads" and "clips" folders.

Needs Windows 10/11. Nothing else to install — ffmpeg is included.
